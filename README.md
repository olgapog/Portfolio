# Personal Portfolio Website

A clean, modern and fully responsive personal portfolio website designed to showcase my projects, skills and experience as a web developer. Built with semantic HTML5 and modular SASS/SCSS.

[Live Demo](https://olgapog.github.io/Portfolio/)

---

## 🛠 Tech Stack & Tools

- **HTML5** - Semantic markup and accessible structure (a11y).

- **CSS3/SASS (SCSS)** - BEM methodology, custom properties, and responsive layout.

- **npm-run-all & live-server** - Efficient local development workflow with automatic SASS compilation and hot reloading.

- **Git & GitHub Pages** - Version control and deployment.

---

## 📱 Features and Highlights

- **Responsive Design**: Fluid layout crafted with a desktop-first approach, adapting smoothly across desktop, tablet, and mobile viewports.

- **Custom Responsive Text Handling**: Targeted line breaks for copyright and heading text for cleaner layout balance.

- **Vector Assets**: Lightweight custom SVG favicon and optimized graphics.

- **Performance Focused**: Pure, lightweight code without heavy external frameworks for fast load times.

---

## 🚀 Local Development Setup

To clone and run this project locally on your machine:

### 1. Clone the repository

```bash
git clone https://github.com/olgapog/Portfolio.git
cd Portfolio
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```
